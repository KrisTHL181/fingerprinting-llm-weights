中间层表征对齐 · 同义句探针 · 权重相似性推断

用近义句作为探针，估算表征协方差，推断两个 LLM 是否权重几乎相同

在受控小模型 Qwen3.5-0.8B 上做离散 token 优化，把"含义相同"定义为中间层表征接近；再把一组近义句当作模型的探针，用其表征协方差与 logprob 指纹去标定"权重扰动尺度 ↔ 指纹发散度"——并检验这一方法能否迁移到只有 top-20 logprobs 可用的云端大模型。

模型 Qwen/Qwen3.5-0.8B (24 层 · hidden 1024 · vocab 248k) 目标 DeepSeek-V4-Flash · 共享词表 108,773 tokens 设备 RTX 3080 Ti 12GB

方法

整条流水线

四个环环相扣的步骤，最后一步给出"两个模型权重差多少"的定量估计。

  1. 近义探针：对每个参考句，在共享子词表内生成一组近义候选句（嵌入近邻 + 潜表征对齐筛选）。
  2. 指纹：取每个候选在中间层的 pooled hidden，中心化后估表征协方差 Σ；另取每个候选的逐句 logprob 向量——后者与 DeepSeek API 能给的 top-20 logprobs 同构，是可迁移指纹。
  3. 噪声标定：给 Qwen 权重加 N(0,(r·σ)²) 噪声，多尺度重算指纹，测发散度 D(r)，建立单调标定曲线。
  4. 推断：实测目标模型指纹差异，反查标定曲线 → 隐含权重相对扰动尺度 r。同 tokenizer 下方法成立；跨 tokenizer 需共享词表对齐。

实验序列

五个受控实验

每一步都先检验前提再前进——编号即实验顺序，每一步否定了/确认了一个子命题。

证伪

01

单层潜对齐不足以定义"含义相同"

离散搜索总能找到中间表征极近（cos≈0.98）但语义破碎的序列。例：…lazy dog. → …ducks Mark!。表征是多对一映射，存在指数级退化解。

弱信号成立

02

hidden 距离是含义的有效弱信号

真实同义句在所有中间层都比随机句更接近（cos 0.91–0.95 vs 0.60–0.73，gap 恒正 ~0.2–0.3）。可区分，但不足以保证。

可行

03

受限同义词搜索产出流畅近义句

候选限定为嵌入近邻（共享词表内）+ 潜对齐作选择目标 → morning→afternoon 等合理替换，cos 0.99。

标定成立

04

协方差 + 权重噪声标定曲线单调

D_logp ≈ 4.9·r（层8·共享词表），层16 斜率 7.6，同 tokenizer 下 Qwen vs Qwen+5% 噪声 top-20 Jaccard = 0.82。

受限

05

跨模型对照受 tokenizer 制约

共享词表对齐后 Qwen vs DeepSeek top-k Jaccard ≈ 0.01——两模型确实不同；命中的共享 token 上 logp 却很接近（如 " −6.63 vs −5.80）。

判别力检验 · 前提的边界

真实同义句在所有中间层都显著比随机句更接近：层 16 处同义 cos 0.922 vs 随机 0.600（gap 0.322）。所以"hidden 距离"是含义的弱信号（必要方向的判据），但因多对一结构，它不充分——不能作为无约束的生成准则。

迁移

从受控小模型到云端大模型

核心前提：生成的离散序列只用共享子词表 token，因此天然可被目标 tokenizer 无损切分。跨模型比较需在共享词表上对齐。

  • 同 tokenizer 控制（方法有效性证明）：Qwen vs Qwen+5% 噪声的 next-token top-20 Jaccard = 0.82——方法能干净地检测权重变化。
  • 跨 tokenizer：原始 token 字符串比较零重叠是假象，源于两模型词表/切分不同；共享词表对齐后 Jaccard ≈ 0.012，命中的共享 token 上 logp 高度接近。
  • API 限制：DeepSeek 为推理模型，需 thinking disabled 且不设 temperature=0（否则 top-k logprobs 退化为 0.0/−9999 占位），且 top_logprobs 上限 20。

诚实的结论

Qwen 与 DeepSeek 是真正不同的模型（架构/大小/训练不同），共享词表上的 top-k 预测重叠极低（Jaccard≈0.01）。对它们，"权重是否几乎相同"的答案是否定的——这由跨架构差异主导，而非权重噪声尺度能单独解释。标定方法的价值在于：在相同 tokenizer / 相同架构内，它能定量地把"指纹差异"映射回"权重扰动尺度 r"。

结论

交付了什么

  1. 一个可复现的离散 token 优化库（HotFlip 梯度引导束搜索 + 受限同义词搜索），在共享子词表内生成潜对齐的近义句。
  2. 一条验证过的权重相似性标定曲线：D_logp ≈ 4.9–7.6·r，单调、多层/多配置稳健、共享词表一致。
  3. 对前提的双向检验：hidden 距离是含义的弱信号（成立）但不充分（证伪）；受限同义词空间 + 潜对齐能产出流畅近义句。
  4. 跨模型迁移的可行性边界：共享词表保证 token 级可迁移；但跨架构的 logprob 比较受 tokenizer 与 API top-20 限制，需共享词表对齐才可比。
